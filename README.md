В ходе лабораторной работы было разработано веб-приложение на Python с использованием Flask и SQLite. Приложение позволяет регистрировать пользователей, выполнять вход в аккаунт и просматривать профиль.

В приложении были реализованы две уязвимости OWASP Top 10: SQL Injection и IDOR. После этого были написаны скрипты для проверки уязвимостей и внесены исправления.

app.py — основной файл приложения. Содержит маршруты регистрации, входа, профиля и выхода из аккаунта.
database.py — создание базы данных SQLite и подключение к ней.
users.db — база данных с информацией о зарегистрированных пользователях.
register.html — страница регистрации.
login.html — страница авторизации.
profile.html — страница профиля пользователя.
sql_injection.py — Python-скрипт для проверки SQL Injection.
idor.py — Python-скрипт для проверки доступа к чужим профилям.
security_fix.diff — файл с изменениями, внесёнными для устранения уязвимостей.
README.md — описание проекта и инструкции по запуску.

Принцип работы
1. Пользователь регистрируется, его данные сохраняются в SQLite.
2. При входе приложение проверяет логин и пароль.
3. После авторизации пользователь попадает в свой профиль.
4. Скрипты из папки exploits проверяют наличие SQL Injection и IDOR.
5. После обнаружения уязвимостей приложение исправляется:
   - SQL Injection — используется параметризованный SQL-запрос.
   - IDOR — добавляется проверка ID пользователя через сессию.
6. Файл security_fix.diff содержит изменения, сделанные для устранения уязвимостей.
